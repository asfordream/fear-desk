# feardeskreview 用户使用指南

更新日期：2026-10-06。适用：本机运行的交割单复盘。云端复盘目前暂缓发布。

## 1. 先认识三个页面

| 页面 | 用途 | 数据含义 |
| --- | --- | --- |
| 市场总览 | 观察标的恐慌值和形态 | 行情信号，不是你的成交或盈亏 |
| feardeskreview／复盘总览 | 查成交、损益、计划和交易证据 | 私人交易账本 |
| 收盘日报 | 查看市场日报 | 与复盘月报独立 |

恐慌值和形态判断是两个概念。信号不代表你已经下单；真实交易记录也不会自动生成你当时的交易理由。

## 2. 打开和解锁

1. 启动本机复盘服务。当前电脑已配置“启动复盘”快捷脚本，可复用现有私人数据库和运行环境。
2. 从启动入口打开浏览器。启动入口包含本次服务的本机解锁凭据，不要转发。
3. 解锁后日常访问地址是 `http://127.0.0.1:5191/review`。
4. 如果提示“本机复盘入口尚未解锁”，重新通过启动入口打开。只点普通地址或“重试”不能建立首次登录。

Chrome 和 Codex 内置浏览器的会话独立，需要分别解锁。服务重启会更新解锁凭据；会话到期后也需要重新解锁。不能拿旧启动链接解锁新服务。

关闭网页不会关闭后台；电脑关机、休眠或后台服务停止，会暂停本机采集和月报任务，下一次启动再恢复。本机地址不能在另一台电脑直接使用。

## 3. 切换真实空间和月份

“复盘总览”下面筛选栏最左侧是**空间**：

- **示例·合成数据**：功能演练。这里的交易和金额不计入你的真实账本。
- **真实·本人资料**：已接入的实盘成交、证据和复盘资料。

空间右侧可选月份，然后选择账户、币种、市场。筛选选项来自所选月份的成交；该月份没有成交时，只显示“全部”，并提示没有数据。切换空间时会清空旧筛选，避免把示例账户带到真实页面。

当前旧实盘账本的 141 条成交属于 **2026 年 8 月**。选择 9 月不会显示这些 8 月记录；需要采集或导入 9 月数据。

不同币种分别展示。没有有据汇率时，不把美元、港元或其他币种合并成一个盈亏数字。

## 4. 首次使用建议顺序

1. 解锁页面，选择“真实·本人资料”。
2. 选择已有数据的月份，确认月内成交明细和账户筛选有内容。
3. 在“资料导入”读取富途账户，采集你需要的其他月份。
4. 查看成交原始证据，补齐核算缺口。
5. 完成期初成本、覆盖资料和单据核对后，保存月报版本。
6. 对重要交易建立档案、关联成交、填写复盘并沉淀经验。

## 5. 富途只读采集

### 5.1 准备条件

- 本机 OpenD 已启动并登录富途实盘账户。
- 账户具有相应市场的读取权限。
- Python 采集服务和网页服务都保持运行。

“OpenD 本机可达”只表示本机端口可连接。点击“读取富途账户”成功后，才证明本次账户读取可用。采集接口只读，不提供下单、撤单或交易解锁操作。

### 5.2 手动采集某个月

1. 在页面上方选择目标月份。
2. 打开**资料导入 → 富途只读采集**。
3. 点击**读取富途账户**，选择实盘账户和采集市场。
4. 点击**采集所选月份**。
5. 查看“已排队／采集中／已入库／存在字段缺口／失败”的状态以及新增、重复、冲突数量。
6. 完成后回到“损益与日历”，核对成交和月份。

采集任务在后台处理，关闭网页仍可继续。失败不会把未知数据填成零。重复点击不会并行启动第二个采集；完成后可再次回查同月，稳定成交键相同的记录会去重。

### 5.3 每小时自动采集

选好账户和市场后，点击**开启每小时自动采集**。系统持久保存这个范围；首次执行和后续每小时检查当前月与上一月，补新成交。历史其他月份请使用手动采集。

可以点击**暂停自动采集**；已经开始的只读查询会完成，后续自动采集停止。当前版本一次配置一个账户及一个市场；其他范围需切换后采集。采集进行中不能切换范围。

网络、登录、权限或 OpenD 出问题时会显示失败；恢复条件后可重新采集，启用自动采集的任务也会在下一次到期重试。已有记录和原始证据不删除。

### 5.4 采集成功不代表所有金额可核算

当前富途历史适配器可能无法给出充分的证券类型、合约乘数、开平标识、完整费用和生命周期事件。这些信息缺失时，成交可以入库，盈亏仍可能处于部分可算或草稿状态。

不得仅因合约代码像期权就填入乘数 100，不得用零补缺费用，也不自动认定股票卖出对应哪次开仓。正式费用、调整合约、行权、指派和期初成本需有券商资料或其他可核对证据。

## 6. 看懂损益与日历

| 项目 | 含义 |
| --- | --- |
| 已实现毛盈亏 | 可核算的开平匹配价格结果，未扣分摊费用 |
| 已实现净盈亏 | 可核算的毛盈亏减完整分摊费用；缺费用时显示未知 |
| 已实现分摊费用 | 分配给本月平仓片段的开平费用 |
| 本月发生成交费用 | 费用实际发生于本月的成交费用，与平仓分摊口径不同 |
| 未实现盈亏 | 当前未接入完整历史估值，不以零表示 |

交易日历按成交记录所在市场的当地日期显示。点击某日过滤明细，点击“显示整月”取消日期过滤。空白日期和“未核实”不表示当天确定没有交易。

已实现账务片段使用 FIFO 匹配，**片段数不等于策略交易次数**。点击金额或“原始行与哈希”可以追溯对应成交证据。顶部汇总按账户／币种的整月口径展示，市场和日期筛选作用于下面明细，以页面提示为准。

## 7. 交易档案与当时信号

- **信号与标的**：记录带来源、数据时间、生成时间和规则版本的信号。保存当前信号不等于补回历史信号。
- **交易档案**：填写标的、账户、策略、方向、理由、持有期、数量、预算、最大亏损、失效条件和退出计划。
- 必填信息和经验检查完成后才能确认计划；确认后版本冻结，修订需追加版本及原因。
- 将真实成交分配到档案时，分配数量不能超过已有成交数量。相同代码不自动代表同一笔策略。
- 首次立案晚于成交，会标为事后立案。事后回忆与当时理由分开记录，不用回忆替代事前证据。
- **经验库**：每条经验需关联来源案例，说明问题、具体动作和验证方式。

## 8. 月报与任务

“保存或复用报告版本”保存当前核算输入和结果。输入未变时复用版本；资料或修订变化后会形成新版本，旧版保留。

“月报与任务”可查看每月执行状态、版本、保存时间，打开旧版本、导出 JSON 或验证复算。每月 3 日北京时间 09:00 起检查上月报告；本机服务未运行时，后续启动按月补跑。

资料不足仍可能生成草稿；自动生成不表示你已经审阅，也不表示已与正式月结单核对。

| 状态 | 如何理解 |
| --- | --- |
| DRAFT | 缺少必要交易／覆盖／成本等资料，先补证据 |
| PARTIAL | 部分范围可核算，仍有缺口或核对未完成 |
| FINAL | 当前网页不会仅因采集或计算成功就认定完整正式核对 |

看报告时分别检查核算、覆盖、单据核对、本人审阅和估值状态，不把一个“已核算”当成全报告完成。

## 9. 文件／JSON 导入及修订

“资料导入”也保留 JSON 导入入口。成交使用对象数组，金额和数量使用十进制字符串；账户填写脱敏键。原始行归档，稳定键去重；同键内容不同会记冲突并保留原事实。

追加期初、覆盖、事件、单据和汇率资料时，需要相应字段、来源证据及版本。已有资料需用其当前版本追加；版本冲突时重新读取，不能覆盖旧记录。技术人员可协助转换券商导出，用户无需手工编写大批 JSON。

旧账本接入会先备份目标库，再保留成交键、原始行、缺口和有据修订；源库只读。身份脱敏密钥不一致时停止接入，避免把同一账户变成另一个账户。缺稳定键、身份和币种的旧历史账本不能直接混入已确认的实盘范围；需先核对。

## 10. 常见问题

| 现象 | 处理 |
| --- | --- |
| 本机入口尚未解锁 | 从当前服务的启动入口重新打开；不同浏览器分别解锁 |
| 账户、币种、市场只有“全部” | 查看所选月份是否有成交；切换已有月份或采集该月 |
| OpenD 可达但账户读取失败 | 检查 OpenD 登录、市场权限及 Python 富途 SDK |
| 采集成功但没有盈亏 | 看成交是否缺证券类型、乘数、开平、费用或期初成本 |
| 九月看不到旧 141 条成交 | 旧记录属于八月；九月需另外采集或导入 |
| 自动任务不运行 | 电脑、OpenD 和本机后台必须保持运行；检查开关和最近状态 |
| 月报仍是旧版本 | 等采集和核算完成，再刷新；新资料会追加版本，不覆盖旧版 |
| 手机打不开本机地址 | 当前只支持本机；云端复盘按用户要求暂缓发布 |

## 11. 数据保存边界

真实账本、示例账本、账户脱敏密钥和运行配置分别保存在本机私人目录。源码上传 GitHub 不携带这些资料。当前已连接的是本机数据，未将私人交易资料上传云端。原信号网站保持独立。

### 技术人员启动附录

新电脑可按分支说明安装依赖，用 `npm run review:local` 启动。已有数据的电脑必须设置正确的 `REVIEW_STATE` 和 `REVIEW_PYTHON`，避免误启动一份空数据库。当前电脑的启动快捷脚本已经固定现有私人目录，不要用新建空目录替代。

手动接入已确认的原账本可使用 `local-review/ledger_link.py` 的 `--source`、`--state` 参数；操作前核对来源和备份。私人数据库和密钥不得提交 Git。
