# 交易规则与观察使用说明

1. 从本机启动入口解锁复盘，再打开 `/rules`（交易规则与观察）。
2. 默认规则为单日复权收盘跌幅严格超过5%，最近一次触发之后第3个美股交易日观察。
3. 新增规则时选择自动模板或人工检查。人工文字不被程序解释为交易条件，也不自动判定通过。
4. 用左侧拖动柄上下移动，或点上移/下移；顺序保存后网页及独立提醒共用。
5. 编辑生成新版本，只对后续交易日生效；停用或删除立即停止该规则相关提醒，保留历史。删除使用页内确认。
6. 更新观察清单会读取现有复权行情；页面标明日期、检查时间和缺数。首次启用不回填历史，不会因为没有触发就推断数据齐全。
7. 到期后点击标记已处理，停止该事项提醒；历史中可撤销，但规则停用或有后续触发时不能恢复旧提醒。
8. 北京时间周一至周六14点通过现有机器人单独发送规则提醒。有启用规则、但没有触发股票时仍发规则；没有启用规则不发空提醒。
9. 发布当天不补发。发送中或结果未知不自动重发；只有明确成功回执才算送达。

当前不自动下单、不执行任意规则脚本、不调用大模型。规则只是你的观察清单，不等于已经开仓。原型、需求、工程方案和验证统一在 `docs/versions/v0.3.0/`。

## 收盘日报与飞书卡片

- 股票行中的「财报」用红色粗体，显示未来七个自然日内的财报日期和距收盘日的自然日天数。
- 「大跌」用绿色粗体，仅在大跌日期前显示一次。记录显示跌幅和已过美股交易日，大跌当天为零，达到观察日后标记「可观察」。当前本机规则阈值为跌幅达到 7%。
- 候选区标题用黑色粗体。
- 飞书验收使用 2026-10-30 历史截面。用户截图确认红绿粗体、大跌日期和两种计数均已显示。该验收为人工发送。
