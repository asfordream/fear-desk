# 本机统一运行指南

主要代码目录为当前仓库 `fear-desk-github`，主要分支 `feardeskreview`。该目录名字中的github仅是历史命名，不是云端执行。

## 启动

日常由macOS后台托管。需要手动启动时，在本仓库执行 `npm run review:local`；已有后台服务运行时不要重复启动。当前机器的解释器由忽略的本机配置读取，不依赖旧信号目录。后台日志位于 `~/Library/Logs/FearDesk/`。

## 入口

网页 `http://127.0.0.1:5191/`，复盘 `/review`，日报 `/reports`。私人核算18761只作内部API。登录Mac自动启动，日任务北京时间周一至周六14点执行；电脑需开机联网、不休眠。

## 私人运行目录（均不入Git）

- `.wrangler/`：信号行情、评分、日报和投递围栏。
- `.sites-runtime/local-daily/`：机器人秘密配置、持久调度状态及日志。
- `.review-state/`：私人账本、会话入口、配置及证据。
- 原始券商资料如仍引用仓库外路径，保留原路径，不擅自移动。

## 旧目录角色

`fear-desk`保留原信号源码与回退数据，不再作为活动服务；`fear-desk-data`是历史数据库文件；`fear-desk-export`是历史源码包；`fear-desk-qa`是历史验收资料。以上本轮不删除，不代表已经把所有旧资料迁走。

本指南的运行状态以版本验证记录为准，文档生成不等于迁移完成。
