# 目录角色与整理边界

|目录|整合后的角色|
|---|---|
|fear-desk-github|唯一主开发与运行仓库，分支feardeskreview|
|fear-desk|原信号源码及迁移前数据，后台停用，保留回退|
|fear-desk-data|历史analytics.sqlite3，不是当前全部数据的总目录|
|fear-desk-export|历史导出源码包和交付材料，不当作当前源码|
|fear-desk-qa|历史验收截图与记录，暂不移动|

本轮只将活动运行数据复制到主仓库忽略目录，并归类文档。未删除旧目录，未移动仍被账本引用的原始券商证据。旧目录整理删除需要另行核对，不能只凭名称决定。
