# feardeskreview 开发分支

基线：GitHub `fear-desk-daily-pipeline` 信号分支，当前与 `release/0.2.6` 相同，提交 `ed3fe93bc201523b03fb11a18b74b8f6e8986f61`。
分支：`feardeskreview`。本地与远端保持同名并建立跟踪。

产品命名：FearDesk 指信号功能；feardeskreview 指交割单复盘功能。

本分支加入截至 2026-10-06 的本地 FearDesk复盘新增源码：复盘页面、同源私人服务、信号与冻结立案、成交数量关联、证据核算、经验及月度任务代码，以及相关文档和测试。`review-ledger` 收纳原复盘交易项目的 Python 账本模块，克隆后不再依赖开发者本机的兄弟目录。

原功能使用零点二点六基线。本分支仅上传源码，不代表全部产品需求已完成或真实财务资料已核对；完整网页验收和新云端目标另行处理。本分支移除原站点绑定，禁止连接原生产交易数据或自动部署原站点。旧交接文档为当时记录，当前仓库布局以本文为准。

## 本地启动

```sh
npm ci
python3 -m venv review-ledger/.venv
review-ledger/.venv/bin/python -m pip install -r review-ledger/requirements.txt
npm run review:local
```

Python 需 3.11 或以上。本地解锁链接保存在被 Git 忽略的 `.review-state/entry-url.txt`。真实富途采集可另行安装可选 futu SDK 并配置只读 OpenD；不连接时不伪造成交。

## 验证

```sh
node --experimental-strip-types --test tests/*.test.mjs
npm run test:review
npx tsc --noEmit
npm run build
```

可用 `REVIEW_PYTHON` 指定已有 Python 运行环境。`REVIEW_LEDGER_PROJECT` 可显式指定外部账本项目，但默认已使用仓库内源码。

本地数据库、账户映射、券商凭证、运行时解锁密钥、环境文件及交易导出均不得提交。
