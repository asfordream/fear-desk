# 交易规则与观察：工程方案

状态：实现中，未发布。

- 同一仓库和唯一网页入口，不增加网页服务。新规则页面通过现有本机会话与防伪令牌，访问私人核算内部API的独立watch-rules命名空间，避免与原复盘经验库rules混淆。
- 本地 `.review-state/observations.sqlite` 保存规则、不可变版本、评估与触发事项、操作日志和独立提醒投递记录。现有信号D1库通过同源认证的本机只读接口提供观察池和复权收盘日线；Python使用内存快照计算，不直接跨进程打开开发环境的D1 WAL文件。
- 日历复用项目审定的NYSE 2026–2028交易日表，越界报错，不猜测工作日。半日市仍算一个交易日。
- 条件模板固定为复权收盘单日跌幅严格超过阈值，支持安全数值参数；人工规则只是文字，不执行脚本或让模型猜测。
- 创建/编辑默认在尚未收盘的下一有效交易时段生效；不自动回填启用前历史。重复触发替代同规则同股票当前事项，历史触发保留。
- 停用、归档、移出股票池立即停止相关提醒；恢复启用从新生效日开始，不恢复旧事项。已处理可撤销，记录操作日志。
- 原日报与规则提醒采用独立状态和独立锁，失败互不吞掉结果；同排程日规则快照先保存再发送，unknown/sending不自动重发。今日不额外发送；正式自动提醒从启用后的下一排程日开始。
- 卡片超过平台安全大小时明确失败并在页面提示，不静默截断；首期不启用多分片消息。
- 发布前验证：边界跌幅、交易日、连续重置、修改版本、停用/移出、处理撤销、排序持久、并发冲突、独立去重、未知回执、空清单和大卡片。
