# 自动财报日历与版本更新页

## 范围与验收

- 无密钥即可尝试免费公开来源：已登记的公司官方页面/RSS优先，Yahoo公开报价页补充。第三方日期一律标记预计，不能因为网页未写est.就视为官方确认。
- 新增标的、增量更新、每日任务均更新财报日历；打开观察池自动按缓存检查，也可单独刷新，不受纽约收盘时间限制。
- 保存日期/区间、盘前盘后、来源链接、检查时间、失败状态；无法获取时保留之前记录并提示；过去日期不冒充下一次财报。缓存成功24小时、未公布6小时、失败15分钟。
- 精确预计日期参与原有财报窗口修正并标记预计；区间不选任意一天修正。登记/抓取前的历史不回填已知信息；新获取信息统一从纽约下一自然日起才对计算可见（普通交易日和早收市统一保守处理）。
- 人工纠错独立于自动来源，可明确恢复自动。所有决策追加保存，不删除历史。并发刷新与人工修改之间使用校验令牌阻止覆盖。
- 飞书卡片和冻结日报保存来源、可信状态、获取时间及日期区间；旧快照不被更新。
- 版本页显示发布时间、版本号、改动与限制；需求提交后持久化，可切换待评审/计划中/已完成；记录需求不会自动实施代码。
- 必须验证解析日期/区间/错误页/公司错配、历史可见性、人工优先、并发、缓存、入库、冻结快照、授权与手机展示。

## 限制

免费网页会改变结构或限制自动访问；未公告日期无法凭空确认。当前官方来源登记覆盖AAPL/MSFT/NVDA/TSLA/NFLX/CRDO，其他普通股使用Yahoo预计日期。Finnhub可选，需要用户自行配置免费账户密钥；不用付费API。财报正文/结构化财务指标属于后续需求。PCR规则和线上定时触发/实际飞书发送仍待验收。
