## 已实现行为

- **刷新日报**：认证GET只读保存记录，任何时间可用，不推进任务、不生成、不发送。状态和current指针在同一D1读取批次中获取，网页只接受最新一次完整读取。
- **立即生成最新日报**：严格`generate + requestId`手动受理；先持久化，返回202，随后通过请求ExecutionContext登记有界后台执行。没有14点窗口限制，默认无发送意图；响应不确定时沿用原请求编号，重复编号返回原任务或结果。
- **独立定时与恢复**：保留原定时发送意图，手动、原定时请求可合并兼容生成任务且分别保存意图。恢复入口只接受字符串`resume_existing`，仅扫描新流水线已有任务，不新建、不发送或补发。没有新增或调整线上定时任务。
- **检查点和重试**：冻结观察池、解析SPY收盘日、逐只获取行情、财报、逐只计算、完整性验证、发布分阶段持久化。每片有25秒数据库执行期限、120秒租约；drain有20秒执行预算。中断保留检查点，回收预留预算，设置重试等待；最多3次失败循环、30分钟累计工作预算。
- **写入保护与原子发布**：每个实际写入检查token、epoch、检查点、输入revision及数据库时间；已有行情和财报写入也共享资源围栏。批次末尾CHECK断言将部分成功转为事务失败。发布一次提交行情、评分、冻结日报、current、任务和因果revision；旧交易日晚完成只进入历史，current不倒退。同内容复用首次生成时间。
- **网页状态**：独立显示目标已收盘日、实际交易日、生成时间、完整性、生成任务和发送状态。当前页在有活动任务时5秒、空闲时30秒只读轮询，隐藏/离线暂停并唤醒；历史页只恢复首次读取，不随current变化。唤醒使用代次保护，避免多条轮询链。
- **版本记录**：APP_VERSION及已发布记录仍为0.2.5；候选0.2.6标记待发布。需求状态增加开发中、待发布、已发布，不把未部署实现记为线上已发布。
