# FearDesk 每日更新与飞书日报

范围：接续已确认的课堂公式和网页设计。群自定义机器人，使用数据库收盘截面生成卡片；PCR 仍明确待完善，形态和筛选独立展示。

## 实现与验收

- 数据库存日报不可变快照、任务日志、发送状态；同内容重复生成复用快照。
- 工作日纽约 16:30 后更新 SPY 和观察池。UTC 多次触发适配夏令时；SPY 必须存在当天已收盘日线，休市不会冒用前日生成当日日报。
- 缺失行情或更新失败不自动发送；预览可展示覆盖不足。新股历史预热独立标注。
- 飞书 JSON 2.0 卡片含总体、最大变化、分区折叠、独立形态/筛选、财报与质量提示。链接指向冻结日报。没有公网地址不发送。
- 服务端保存机器人凭据，默认关闭发送；成功记录不重复发送，结果不确定不盲目重试，明确失败可以手动重试原快照。
- 网页新增日报预览、JSON 导出、运行状态；保留行情、增删标的和财报登记。
- 财报自动源先使用可配置 Finnhub；未配置继续显示需登记。历史采用当时可见财报事件，修改未来日期不会抹掉旧修正。

## 必须运行的验证

`node --experimental-strip-types --test tests/*.test.mjs` 全部通过。

`npx tsc --noEmit --incremental false` 无错误。

`npm run build` 成功，生成 Worker 配置含 cron。

本地 D1：迁移保留原行情；重复生成不增加相同快照；冻结日报不随观察池变化；未配置机器人发送请求拒绝；身份验证和跨站写入仍阻断。

浏览器：打开日报、生成预览、分区展开、导出 JSON、旧快照浏览；375px 无溢出。实际发送和线上定时运行依赖机器人凭据和部署，不能用本地验证代替。
